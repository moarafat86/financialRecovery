# التعافي المالي — خطة الإيراد والتسليم

نظام ويب لمتابعة خطة الإيراد والتسليم للمشاريع، مبني على نفس هيكل جدول Excel «خطة الايراد والتسليم».

## التشغيل
افتح الملف `index.html` مباشرة في المتصفح، ولا يحتاج إلى خادم أو أي تثبيت.

## المزايا
- الجدول بنفس الأعمدة الـ 14 في ملف Excel، ومعها سطر الإجمالي.
- **المتبقي** يُحسب تلقائياً = اجمالي الخطط للتسليم − مسلم.
- مؤشرات أداء: الإيراد، إجمالي الخطط، المسلَّم ونسبته، التسليم مقابل المخطط حتى نوفمبر، المتبقي، والاستحقاقات المتأخرة.
- بحث وفلترة حسب حالة العقد وSegment والجهة وحالة الاستحقاق، مع الفرز بالضغط على رأس أي عمود.
- إضافة مشروع وتعديله وحذفه (بالضغط المزدوج على الصف أو بزر التعديل).
- تصدير إلى Excel واستيراد منه، ويُتعرّف على الأعمدة بأسماء رؤوسها.
- تمييز بصري: الأخضر للتسليم المكتمل، والأحمر للمتأخر، والأصفر لما يستحق خلال 7 أيام.

## الهيكل
```
index.html
assets/css/styles.css     # الهوية اللونية في :root
assets/js/app.js          # منطق النظام
assets/js/seed-data.js    # البيانات الأولية المستخرجة من ملف Excel
assets/vendor/xlsx.full.min.js  # SheetJS 0.18.5 لقراءة ملفات Excel (الاستيراد)
assets/vendor/exceljs.min.js    # ExcelJS 4.4.0 لتصدير ملف Excel منسق بألوان النظام
```

> البيانات تُحفظ حالياً في متصفح المستخدم (localStorage).
